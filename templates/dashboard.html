API Usage Examples

Sending SMS via API

curl -X POST \
  'http://[your-device-ip]/api/sms' \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: your_api_key' \
  -d '{
    "recipient": "+1234567890",
    "message": "Hello from the API!"
}'

Getting Inbox Messages

curl -X GET \
  'http://[your-device-ip]/api/sms/inbox' \
  -H 'X-API-Key: your_api_key'

Getting Outbox Messages

curl -X GET \
  'http://[your-device-ip]/api/sms/outbox' \
  -H 'X-API-Key: your_api_key'

Getting System Logs

curl -X GET \
  'http://[your-device-ip]/api/logs' \
  -H 'X-API-Key: your_api_key'
